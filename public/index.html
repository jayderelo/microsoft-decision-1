Foundry connection

Deploy Microsoft-Decision-1 in Azure Foundry, then add your resource details to the .env file in this project.

AZURE_ENDPOINT=https://YOUR-RESOURCE.services.ai.azure.com
AZURE_API_KEY=your-api-key
DEPLOYMENT_NAME=microsoft-decision-1

Use your actual deployment name. Restart with npm start after saving, then select Decision-1.

⌁Your API key stays on the Node.js server. The browser only receives game state and decision results.
